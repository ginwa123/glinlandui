glinlandui — the CPU rasterizer and the GPU, on the same frame

This page is the browser's peer of the native parity gates: it renders one frame with the software rasterizer, renders the same frame with whichever GPU backend this browser gives us, and prints the per-pixel difference. The toolkit's own standard is 1/255 (see docs/linux-vulkan-backend.md), so a mean of 0.0x with a max of 1 is a pass.
